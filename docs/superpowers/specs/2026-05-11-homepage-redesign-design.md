# 四级真题首页改造设计说明

## 目标

把首页改成更纯粹的工具站入口页，减少介绍性内容和重复内容，让用户进入站点后更快理解一件事：

`这里可以直接进入真题下载页。`

## 改造范围

本次只改首页，不改真题下载页的信息结构，不改试卷预览页链路。

### 包含

- 首页首屏重排
- 首页主文案收缩
- 首页唯一主按钮
- 首页最近更新信息条
- 首页移除多余说明卡片和伪预览区

### 不包含

- 真题下载页布局调整
- 试卷预览页布局调整
- 新增功能页
- 新增批量下载
- 新增搜索

## 首页职责

首页只承担三件事：

1. 说明站点价值
2. 提供唯一主入口
3. 提示最近更新

首页不再承担“缩小版真题页”或“详细介绍页”的职责。

## 首页结构

### 首屏

首屏采用更稳定的双行标题：

- `四级真题`
- `直接下载`

标题下方只保留一小段副文案，强调：

- 不登录
- 不跳转
- 直接拿 PDF

### 主操作

首屏只保留一个主按钮：

- `进入真题下载页`

不再保留首页中的多入口卡片，不再把“关于本站”作为首页主体入口。

### 最近更新

首页保留一个轻量的最近更新信息条，而不是完整预览卡片。

信息条内容包含：

- 模块标题：`最近更新`
- 最新一套真题标题
- 一个次级入口：`查看最新真题`

这个区域的职责是补充内容感与新鲜度，不承担完整真题展示职责。

## 删除项

首页删除以下内容：

- `站点承诺` 大卡片
- `真题下载 / 关于本站` 双入口卡片
- `最新真题预览` 卡片式区域

## 视觉方向

首页需要更克制、更松弛，避免当前版本的两个问题：

1. 首屏标题过重且换行失控
2. 页面主体由多块说明卡片堆叠而成，像介绍页，不像入口页

因此本次视觉方向应为：

- 标题更短
- 主体留白更多
- 操作更集中
- 最近更新更轻

## 实现方式

- 继续使用现有 `src/pages/index.astro`
- 继续复用 `src/layouts/BaseLayout.astro`
- 在 `src/styles/global.css` 中补充首页专用样式
- 使用 `papers[0]` 作为最近更新的信息来源

## 验收标准

满足以下条件即视为完成：

1. 首页首屏标题改为双行短标题
2. 首页主体只保留一个主按钮 `进入真题下载页`
3. 首页存在轻量 `最近更新` 信息条
4. 首页不再出现 `站点承诺`
5. 首页不再出现旧的 `最新真题预览`
6. 构建与测试通过
